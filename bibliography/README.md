# Course bibliography

As listed on the [course page](https://edu.info.uaic.ro/metode-formale-inginerie-software/) on 1 October 2026.

1. Boro Sitnikovski. *Introducing Software Verification with Dafny Language — Proving Program Correctness.* ISBN 978-1-4842-7977-9.
2. Michael Huth and Mark Ryan. *Logic in Computer Science: Modelling and Reasoning about Systems.* Cambridge University Press.
3. Benjamin C. Pierce. *Types and Programming Languages.* MIT Press, 2002.
4. Glynn Winskel. *The Formal Semantics of Programming Languages — An Introduction.* MIT Press, 1993. [Downloaded PDF](TheFormalSemanticsOfProgrammingLanguages.pdf) · [Original link](https://www.cin.ufpe.br/~if721/intranet/TheFormalSemanticsofProgrammingLanguages.pdf).
5. Flemming Nielson, Hanne R. Nielson and Chris Hankin. *Principles of Program Analysis.* Listed on the course page as 2nd edition, Springer, 2005.
6. Leslie Lamport. *Specifying Systems: The TLA+ Language and Tools.* Addison-Wesley, 2002.
7. Thomas Noll. [*Static Program Analysis*](https://moves.rwth-aachen.de/teaching/ws-1617/spa/), RWTH Aachen, 2016–2017.
8. University of Pennsylvania. [*CIS 700: Software Analysis and Testing*](https://www.cis.upenn.edu/~mhnaik/edu/cis700/), Fall 2018.
9. [*Maude Manual*](https://maude.lcc.uma.es/maude-manual/), 2024.
