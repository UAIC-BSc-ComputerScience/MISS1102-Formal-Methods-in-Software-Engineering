Overview

This course is about applying formal methods to real software: the mathematical and logical techniques that let us specify precisely what a program should do and then prove that it does it. The emphasis is practical — we write specifications, verify programs with tools, and reason about their correctness — so that the ideas are usable by engineers, not only by specialists.

What we cover

  • Formal systems and proofs: languages, inference rules, propositional logic, and rigorous proofs
  • Operational semantics of a simple imperative language
  • Hoare logic and the weakest-precondition / strongest-postcondition calculi
  • Dafny, a verification-aware language: contracts (requires/ensures), loop invariants, and SMT-backed automated verification
  • Lean 4, an interactive theorem prover: functional programming, proofs by induction, and certified algorithms
  • Certified compilation and type systems
  • Introduction to static analysis
